# AutoPostAdsBot

Аккуратный планировщик объявлений (фото + текст) в Telegram-группы, где реклама разрешена.
Telethon (юзербот) + aiogram 3 (управляющий бот) + APScheduler-подобный цикл + SQLite.

> **Риск.** Постинг от имени аккаунта через неофициальный клиент может привести к ограничению
> или заморозке аккаунта Заказчика. Антибан-правила ниже снижают риск, но не гарантируют его отсутствие.
> Используйте отдельный рабочий аккаунт, а не основной.

## Антибан-правила (зашиты в `bot/limits.py`, Заказчик не может отключить)
- интервал на группу ≥ 3 ч; применяется самое строгое из: выбор Заказчика, правило группы «N в сутки», прогрев;
- jitter ±15%, пауза между отправками 40–120 с, старты новых объявлений разнесены;
- не более 20 постов/час и 150/сутки на аккаунт;
- тихие часы 23:00–08:00 (GMT+6, настраивается `TZ_OFFSET_HOURS`);
- прогрев первые 14 дней: до 5 групп, интервал ≥ 12 ч;
- `PeerFloodError` → остановка всех отправок; бан/отозванная сессия → стоп; 3 ошибки подряд → группа отключается;
- только группы, где Заказчик вручную подтвердил «реклама разрешена, правила проверены»;
- 2–3 варианта текста по кругу.

## Запуск
1. `cp .env.example .env` и заполнить (BotFather токен, `OWNER_ID`, `API_ID/API_HASH` с my.telegram.org, `FERNET_KEY`).
2. **На ПК Исполнителя** при личной встрече (код вводить с разделителями, не пересылать через Telegram):
   `python scripts/generate_session.py > session.enc`
3. На сервере: `python scripts/import_session.py "+996***12" < session.enc`, затем удалить `session.enc`.
4. `docker compose up -d --build`

Сессия хранится в БД только в зашифрованном виде (Fernet); ключ — только в `.env` на сервере.
Доступ к боту — только с `OWNER_ID`.

## Команды
`/new` · `/ads` (пауза/продолжить/удалить) · `/groups` · `/status` · `/pause_all` · `/resume_all` · `/help`
